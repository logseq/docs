Cards are blocks tagged `#Card`, scheduled by the [FSRS algorithm](https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler) — the same family of scheduler Anki uses. No decks to manage; any block can become a card.

## Create cards

- Tag a block `#Card`.
- Select several blocks → right-click → `Make a flashcard`.

Write the card however you like — a question on the block with the answer nested below is the usual pattern.

## Review

Open **Flashcards** from the left sidebar. Due cards come up one at a time; reveal the answer and rate yourself on a 4-level scale. FSRS reschedules accordingly.

## Manage cards

The `#Card` page lists every card in a table — `Due` tells you when each comes up next. Filter to overdue, sort by due date, or bulk-retag like any other [view](/features/views).
