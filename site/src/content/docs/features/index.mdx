Everything in this section is built from the same ingredients — tags, properties, and nodes — which means each feature is customizable the same way: open its tag page, add or reconfigure properties, and the feature reshapes itself.

- [Tasks](/features/tasks) — statuses, deadlines, repeating tasks
- [Queries](/features/queries) — Query Builder + advanced (Datascript) queries
- [Views & tables](/features/views) — sortable, filterable, groupable node tables everywhere
- [Templates](/features/templates) — reusable block skeletons, including auto-applied ones
- [Flashcards](/features/flashcards) — spaced repetition with FSRS
- [Assets & PDF](/features/assets) — files, images, PDF highlights
- [Publish](/features/publish) — share read-only pages to the web
- [Search & shortcuts](/features/shortcuts) — command palette and keyboard map
- [Plugins](/features/plugins) — community extensions that support DB
