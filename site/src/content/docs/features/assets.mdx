An asset is a node tagged `#Asset` backed by a real file in the graph's `assets/` folder — images, PDFs, audio, whatever you drop in.

## Add files

- Drag a file onto a block.
- On the `#Asset` page, click `+ New` under the table.
- External URL or local path → click the link, choose to make it an asset — the file copies in.

## Manage

The `#Asset` page's table is the inventory — rename, delete, filter. Switch the view to **Gallery** for a visual browse of images.

## PDF annotations

Open a PDF asset and highlight or annotate it. Every annotation creates a node tagged `#PDF Annotation` linked back to the exact spot — so your highlights join the graph like everything else: linkable, taggable, queryable.
