Logseq is an outliner for your notes, tasks, and knowledge. Everything you write lives in a local database on your machine — plain text and open data all the way down, no account required, no lock-in, works offline.

This site documents the current **DB version** of Logseq, where pages and blocks live in a real database instead of markdown files. If you used the older file-based version, the [DB vs OG](/db-vs-og) page lists what changed.

## Why people pick Logseq

  <Card title="Local first" icon="ph:hard-drives">

## What people notice after switching to DB

Real reports from people who moved off the file version:

- **Big graphs just open.** The file version famously choked on large graphs — DB graphs with tens of thousands of pages load fine.
- **Sync that doesn't eat your notes.** No more juggling Git, Syncthing, or Dropbox and finding conflict files. DB sync is real-time, end-to-end encrypted, and you can run it yourself.
- **You stop writing query syntax.** "Haven't had a single case where I needed to look up a query syntax," one user reported — tag pages and the query builder cover it.
- **Cleaner editing.** Collapsible properties, a real date picker on tasks, tags that carry their own schema.
