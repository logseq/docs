Logseq is an outliner for your notes, tasks, and knowledge. Everything you write lives in a local database on your machine — plain text and open data all the way down, no account required, no lock-in, works offline.

This site documents the current **DB version** of Logseq, where pages and blocks live in a real database instead of markdown files. If you used the older file-based version, the [DB vs OG](/db-vs-og) page lists what changed.

## Why people pick Logseq

<CardGrid>
  <Card title="Local first" icon="ph:hard-drives">
    Your graph is a SQLite file on your machine. Read it, back it up, script against it, walk away with it. Works fully offline.
  </Card>
  <Card title="You own the data" icon="ph:key">
    Open schema, EDN export of everything, exports readable in any editor. Your notes outlive the app.
  </Card>
  <Card title="Structured notes, not folders" icon="ph:graph">
    Every block can link to any other. Tags, properties, and queries turn scattered notes into a database you shape yourself.
  </Card>
  <Card title="Scriptable" icon="ph:terminal">
    A real CLI, an MCP server, an HTTP API, and a scripting runtime. Automate your graph like you automate code.
  </Card>
  <Card title="Sync you control" icon="ph:cloud-arrow-down">
    End-to-end encrypted sync between devices — and you can run the whole sync server yourself if you want to.
  </Card>
  <Card title="Open source" icon="ph:code">
    AGPL-licensed, built in public on GitHub, extensible with community plugins.
  </Card>
</CardGrid>
