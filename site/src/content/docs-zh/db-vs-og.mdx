DB 版最大的变化是：笔记从「每页一个 Markdown 文件」变成了「一个 **SQLite 数据库**」。这一个改动解锁了几乎所有新东西——真正的属性、类型化数据、可继承字段的标签、表格、快速查询。核心思想没变：一切仍然是互相链接的块和页面，一切仍然在你的机器上。

## 没变的

- 大纲。块、缩进、缩放聚焦、`[[链接]]`——原封不动。
- 本地优先。不需要账号，离线可用，数据在磁盘上。
- Journal、查询、闪卡、模板、发布——功能都在，大部分基于数据库重做了。

## 变了的

| 方面 | OG（文件版） | DB 版 |
| --- | --- | --- |
| 存储 | 每页一个 markdown/org 文件 | 每个图谱一个 `db.sqlite` |
| 页面 vs 块 | 两种不同的东西 | 都是**节点**——链接、标签、属性、嵌入方式一样 |
| 属性 | `property::` 语法的文本键值，无类型 | 有类型：Text、Number、Date、Checkbox、Url、Node——带选项、默认值、显示位置 |
| 标签 | 纯文本 `#tag` | 标签是真实对象，带有每个成员继承的**标签属性**，还能有父标签 |
| 任务 | `TODO`/`DOING`/`NOW`/`LATER`/`WAIT` 关键字 | 任务是打了 `#Task` 的块，带可自定义的 `Status` 属性和选项 |
| 查询 | 查询块里的 simple + advanced | Query Builder（simple）和 advanced——加上任意标签/属性上的表格视图 |
| 块引用 | `((uuid))` 语法 | 统一成 `[[ ]]`——一个链接可以指向任意节点，页面或块都行 |
| 配置 | `config.edn` | 没有 `config.edn`，设置在界面里按图谱配置 |
| Org mode | 支持 | 不支持 |
| 白板 | 有 | 还没有 |
| 幻灯片 | 内置演示 | 移除了 |

## DB 版新增的

- **表格**——每个标签页、属性页、查询结果都是类电子表格：排序、筛选、分组、直接编辑。
- **Node 类型属性**——属性值可以指向另一个节点，并限定只能选某个标签的节点（比如 `author` 只接受 `#Person`）。
- **标签继承**——`#Audiobook` 继承 `#Book` 和 `#MediaObject`，同时拿到三个父级的属性。
- **重复任务**——做完的任务按可配置的间隔自动重新排期。
- **回收站**——删除的页面 30 天内可恢复。
- **双向属性**——书上的 `author` 链接会在作者页面自动显示「Books」列表。
- **CLI、MCP server、HTTP API**——真正的自动化接口，见 [CLI](/zh/cli)。

## 迁移注意

- Markdown 文件会整体导入——导入器把旧任务关键字映射到新状态、旧属性映射到类型化属性。完整说明和选项见 [迁移](/zh/migrate)。
- 旧的「发布成静态网站」功能还在；新的 [Publish](/zh/features/publish) 是把单个页面分享到 `logseq.io`。
- 如果你依赖 `config.edn`（自定义 CSS、默认筛选、journal 标题格式），这些设置现在大多在应用内的 **Settings** 或按图谱配置。
