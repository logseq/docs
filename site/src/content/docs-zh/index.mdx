Logseq 是一个大纲式笔记工具，用来记笔记、管任务、攒知识。你写的所有内容都存在本机的一个数据库里——纯文本、开放格式，不需要账号，不被锁定，完全离线可用。

本站文档面向当前的 **DB 版本**：页面和块（block）存放在真正的数据库里，而不是 Markdown 文件。如果你用过旧的文件版（OG），[DB vs OG](/zh/db-vs-og) 一页列清了所有变化。

## 为什么选 Logseq

<CardGrid>
  <Card title="本地优先" icon="ph:hard-drives">
    你的图谱（graph）就是本机上的一个 SQLite 文件。能读、能备份、能写脚本处理、随时带走。完全离线可用。
  </Card>
  <Card title="数据属于你" icon="ph:key">
    开放的数据结构、全量 EDN 导出、可读性良好的导出的路径、文件格式都不锁定你。笔记的寿命比应用更长。
  </Card>
  <Card title="结构化笔记，而非文件夹" icon="ph:graph">
    任何块都能链接到其他块。标签、属性、查询把零散的笔记变成你自己塑造的数据库。
  </Card>
  <Card title="可编程" icon="ph:terminal">
    真正的 CLI、MCP server、HTTP API 和脚本运行时。像自动化代码一样自动化你的图谱。
  </Card>
  <Card title="自己掌控同步" icon="ph:cloud-arrow-down">
    设备间端到端加密同步——如果你愿意，整个 sync 服务器都可以自己跑。
  </Card>
  <Card title="开源" icon="ph:code">
    AGPL 协议，GitHub 上公开开发，可用社区插件扩展。
  </Card>
</CardGrid>

## 换了 DB 版之后大家的真实感受

从文件版迁过来的用户实际反馈：

- **大 graph 终于打得开了。** 文件版在大 graph 上是出名的卡——DB 版几万个页面照样秒开。
- **同步不再丢笔记。** 不用再折腾 Git、Syncthing、Dropbox 然后在 `bak` 目录里捡冲突文件。DB 同步是实时的、端到端加密的，还能自己托管。
- **不用再学查询语法。** 有用户原话："一次都没需要查过 query 语法"——标签页和查询构建器就够用了。
- **编辑更干净。** 可折叠的属性、任务上真正的日期选择器、自带 schema 的标签。
