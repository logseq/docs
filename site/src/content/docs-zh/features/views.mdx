视图（view）把一组节点——某标签的成员、查询结果、反向链接、你的页面——渲染成三种布局之一：**Table**（电子表格）、**List**（按页分组的大纲）、**Gallery**（磁贴，适合看资产）。

每个标签页、属性页、查询、Pages 视图、references 区块用的都是同一套视图机制——学会一次 header，处处通用。

## 视图 header

- **视图名**——重命名或删除这个视图。
- **`+` New view**——同一组节点上的多个视图，各自有独立筛选/排序。
- **Filter**——对任意属性设条件。默认 AND；切到 `Match any filter` 变 OR。运算符随类型变（`is`/`is not`、`<`/`>`/`between` 等）。
- **Search**——视图内实时搜索（唯一不持久化的设置）。
- **视图类型**——Table / List / Gallery 切换。
- **三点菜单**——分组、导出、按视图类型的动作。
- **`+` New node**——在视图里建节点；标签页上会自动打标。

除 Search 外，所有设置跨会话保留。

## 分组（Group by）

三点菜单里按任意属性值分组——按状态分列、按作者分书。分组纵向堆叠，共享视图的其他设置。分组本身可按 journal 日期、页面名、创建日期排序，升序降序都行。

DateTime 属性不能分组。

## 表格的细节

表格用起来像电子表格：

- 点列表头排序；可多重排序，从表头图标里移除。
- 三点菜单控制列的显隐。
- 列可以固定、拖拽、调宽。
- 每个单元格行内可编辑——`Enter` 编辑，方向键移动，`Esc` 结束。
- 永远可用的特殊列：`Name`、`Created At`、`Updated At`。
- 底部 `+ New` 原地建行。

## 批量操作

选中若干行（点击，或 `Shift` + 方向键），顶部出现批量操作条：

- **Tag**——给整批加/改/删标签
- **Copy**——复制标题
- **Set Property** / **Unset Property**——批量改字段
- **Delete**
- **三点菜单**——其余批量操作

批量操作在大纲选择上也生效——选中一串块，同样的操作条出现。

## 所见即所得导出

三点菜单里的 `Export EDN` 把*当前可见*的节点——筛过、搜过的——复制成 Build EDN。筛好再导出，是打包图谱一角给别人最快的方式。
