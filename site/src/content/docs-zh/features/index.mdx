这一节的功能都由同样的材料搭成——标签、属性、节点——所以每个功能定制方式也一样：打开它的标签页，加属性或改配置，功能就跟着变形。

- [任务](/zh/features/tasks)——状态、deadline、重复任务
- [查询](/zh/features/queries)——Query Builder + advanced（Datascript）查询
- [视图与表格](/zh/features/views)——到处都是可排序、筛选、分组的节点表格
- [模板](/zh/features/templates)——可复用的块骨架，还能自动应用
- [闪卡](/zh/features/flashcards)——FSRS 间隔重复
- [资产与 PDF](/zh/features/assets)——文件、图片、PDF 高亮
- [发布](/zh/features/publish)——把只读页面分享到网上
- [搜索与快捷键](/zh/features/shortcuts)——命令面板和键盘体系
- [插件](/zh/features/plugins)——支持 DB 的社区扩展
