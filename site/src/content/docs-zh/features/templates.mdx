模板就是打了 `#Template` 的块加上你嵌在它下面的子块。`/Template` 把它复制到任何地方。

## 做一个

1. 在块里写模板名，打 `#Template`。
2. 把模板要包含的内容全部缩进在它下面——多少层都行。
3. `/Template` → 选中 → 整棵树复制进来。

所有模板都躺在 `#Template` 页的表格里，找起来方便。

## 自动套用模板到标签

可选属性 `Apply template to tags` 才是模板的精华：每当带配置标签的节点被创建，模板自动落在它上面。

- 设成 `#Journal` → 每日骨架（清单、晨会提示）出现在每个新 journal 页上。
- 设成 `#Task` → 每个任务自动带上你的子块作为第一级子节点。
- 设成你自己的标签——`#Meeting` → 自动长出参会人/记录/待办三段。

一个标签可以叠多个模板——按顺序套用。

<Aside type="tip">
  模板 + 标签属性覆盖了大多数"数据库条目"工作流：标签定义字段，模板定义章节。
</Aside>
