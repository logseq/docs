资产（asset）是打了 `#Asset`、背后有真实文件的节点，文件存在图谱的 `assets/` 目录——图片、PDF、音频，扔什么是什么。

## 添加文件

- 把文件拖到块上。
- 在 `#Asset` 页表格底下点 `+ New`。
- 外部 URL 或本地路径 → 点链接，选择转成资产——文件复制进来。

## 管理

`#Asset` 页的表格就是库存清单——重命名、删除、筛选。视图切到 **Gallery** 可视化浏览图片。

## PDF 标注

打开 PDF 资产，高亮或做标注。每条标注生成一个打了 `#PDF Annotation`、链回精确位置的节点——你的高亮就此入网：可链接、可打标、可查询。
