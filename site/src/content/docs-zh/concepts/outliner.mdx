Logseq 首先是一个大纲编辑器：你写的所有东西都是嵌套列表里的一个**块（block）**，而不是文档里的一个段落。听起来像限制，用过才知道它换来什么。

## 单位是块，不是文档

普通编辑器里能引用、移动、链接的最小单位是整篇文件；Logseq 里最小的单位是一条 bullet：

- 每个块都能被**链接**——`[[ ]]` 精确指向一条 bullet，两边实时同步。
- 每个块都能**打标签、挂属性**——前一条是任务，后一条是卡片，再后一条是一本书，互不干扰。
- 每个块都能被**嵌入**别处——同一份内容，活灵活现地出现在另一个页面里。
- 每个块都能被**移动**——拖它，或者用 `Move blocks to` 整体挪到别的页面，不用复制粘贴。

写在一个地方，处处复用。上周二会议纪要里埋的那条 todo 依然是真任务——它会出现在 `#Task` 表格里、查询结果里、到期当天的 journal 里。

- `Enter` 新块，`Tab`/`Shift-Tab` 缩进/提升。想法和结构之间没有排版仪式。
- 点块的 bullet（或 zoom 进去）它就变成一个独立页面——专为一个想法开的草稿纸，带自己的反向链接。写完 zoom 回来。
- hover 点箭头折叠任意块。长笔记收成大纲，只展开手头在做的部分。
- 拖 bullet 可以把块连同整棵子树换爹。

## 先写，永远不用"整理"

大纲 + 链接 + 标签意味着结构之后自动长出来。把一切都倒进今天的 journal；哪天某个块长成了项目，打个 `#Project`——它立刻有了表格行、自己的属性、以及你提过它的所有地方的反向链接。

## 键盘优先编辑

| 按键 | 作用 |
| --- | --- |
| `Enter` | 新块 |
| `Tab` / `Shift-Tab` | 缩进 / 提升 |
| `Cmd-Shift-↑/↓` | 上/下移块（拖也行） |
| `/` | 打开[命令菜单](/zh/features/editor-commands) |
| `[[` | 链接节点——搜索器连块的内容也匹配 |
| `Cmd-K` | 搜索 / 跳转 |
| `Esc` | 失焦 / 退出 |

再配上[批量操作](/zh/features/views)——选中一串块，统一打标签、移动或改属性——重排一百个块变成两秒钟的事。
