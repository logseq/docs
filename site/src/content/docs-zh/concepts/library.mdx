**Library** 是个内置页面，把你带命名空间的页面（`父/子`）显示成一棵可编辑的大纲。它回答了"我的文件夹在哪"这个问题：一树能像块一样重排的页面。

## 什么时候用它

- 除了位置别无共性的页面——一棵主题树、一本手册的章节——适合命名空间。
- 共享*字段*的页面（status、author、rating）更适合[标签](/zh/concepts/tags)——标签给你表格和查询，命名空间只给你一条路径。

多数 Logseq 用户完全跳过层级，靠链接和标签活着。想念文件夹的话，Library 就在那。

## 怎么玩

- **把已有页面加进 Library**——Library 页上的按钮；把选中页面挂到某个命名空间下。
- 删掉条目：选中块按 `Backspace` 或 `Cmd-X`——只是移出层级，不删页面本身。
- 把顶层块转成页面（`#Page` 标签）它会落进 Library、挂在父级命名空间下——边写边让树长大的快招。
